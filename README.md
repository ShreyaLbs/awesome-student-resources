# Awesome Student Resources

A community-curated list of free tools, courses, and templates for students.
Every entry is one line. Add yours in under 2 minutes.

## Contents
- [Learning](#learning)
- [Coding](#coding)
- [Design](#design)
- [Productivity](#productivity)
- [Open Source](#open-source)
- [Career](#career)

## Learning
- [CS50](https://cs50.harvard.edu/x/) - Free intro to computer science from Harvard.
- [Khan Academy](https://www.khanacademy.org/) - Free lessons and practice in math, science, and more.
- [MIT OpenCourseWare](https://ocw.mit.edu/) - Free lecture notes, assignments, and exams from MIT courses.
- [NPTEL](https://nptel.ac.in/) - Free engineering and science courses from the IITs and IISc.

## Coding
- [Exercism](https://exercism.org/) - Free coding exercises with mentoring in 70+ languages.
- [freeCodeCamp](https://www.freecodecamp.org/) - Free interactive curriculum for web development and more.
- [GitHub Student Developer Pack](https://education.github.com/pack) - Free developer tools and services for verified students.
- [MDN Web Docs](https://developer.mozilla.org/) - Reference and tutorials for HTML, CSS, and JavaScript.
- [The Odin Project](https://www.theodinproject.com/) - Free full-stack web development curriculum.

## Design
- [Coolors](https://coolors.co/) - Fast color palette generator.
- [Figma](https://www.figma.com/education/) - Free professional plan for students.
- [Google Fonts](https://fonts.google.com/) - Free, open-source fonts for web and print.
- [Lucide](https://lucide.dev/) - Open-source icon set.
- [Penpot](https://penpot.app/) - Open-source design and prototyping tool.
- [unDraw](https://undraw.co/) - Free customizable SVG illustrations.

## Productivity
- [Anki](https://apps.ankiweb.net/) - Free flashcard app with spaced repetition.
- [Excalidraw](https://excalidraw.com/) - Free virtual whiteboard for sketches and diagrams.
- [Obsidian](https://obsidian.md/) - Free local-first note-taking app.
- [Overleaf](https://www.overleaf.com/) - Online LaTeX editor with a free tier.
- [Zotero](https://www.zotero.org/) - Free reference manager for research and citations.

## Open Source
- [First Contributions](https://github.com/firstcontributions/first-contributions) - Hands-on guide to making your first pull request.
- [Good First Issue](https://goodfirstissue.dev/) - Find beginner-friendly issues in open-source projects.
- [Open Source Guides](https://opensource.guide/) - GitHub's guides to contributing to and maintaining projects.

## Career
- [Reactive Resume](https://rxresu.me/) - Free, open-source resume builder.
- [roadmap.sh](https://roadmap.sh/) - Step-by-step career roadmaps for developers.
